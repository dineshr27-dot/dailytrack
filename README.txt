DailyTrack — Mobile navigation update

This update hides the desktop side rail on phones and shows a fixed five-item bottom navigation bar.

Deploy: upload all five files in this folder to the root of the existing GitHub repository, replacing files with matching names. Commit changes and wait for GitHub Pages.

After deployment, close the installed app fully and reopen the website. If it still shows the old layout, use Chrome > Site settings > Storage > Clear (this may clear locally stored tasks, so export your backup first).

Data remains browser-local. Export a JSON backup regularly.
